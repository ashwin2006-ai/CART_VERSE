## ⚡ Common Tasks (Quick Access)

### Add a Product
```
1. Click "📦 Product Listings"
2. Click "+ Add New Product"
3. Fill in: Name, Price, Stock, Images
4. Click "Save Product"
```

### Check Recent Orders
```
1. Dashboard shows "Recent Orders" table
2. Click order ID to see full details
3. Click "Update Status" to mark as shipped
```

### Manage Inventory
```
1. Click "📚 Inventory & Stock"
2. See all products and stock levels
3. Click product to edit stock quantity
4. Set reorder alerts if needed
```

### Create a Discount Coupon
```
1. Click "🎟️  Coupons & Offers"
2. Click "+ Add Coupon"
3. Enter: Code, Discount %, Min Spend
4. Set valid date range
5. Click "Create Coupon"
```

### Respond to Customer Review
```
1. Click "⭐ Reviews"
2. Find the review you want to respond to
3. Click "Reply"
4. Type your response
5. Click "Post Reply"
```

## 🎨 Understanding the Colors

### Status Badges
```
🟢 GREEN     = Active, In Stock, Confirmed
🟡 YELLOW    = Warning, Low Stock, Pending  
🔴 RED       = Error, Out of Stock, Failed
🔵 BLUE      = Info, Shipped, Processing
🟣 PURPLE    = Primary Action, Featured
🟠 ORANGE    = Gold/Accent, Featured Items
```

### Stock Color Coding
```
Stock Level ≥ 10 units: 🟢 GREEN
Stock Level 1-5 units:  🟡 YELLOW (Low Stock)
Stock Level 0 units:    🔴 RED (Out of Stock)
```

## 🎯 Common Use Cases

### Scenario 1: Customer Places Order
```
1. New order appears in Dashboard → Recent Orders
2. Go to "🛒 Orders" tab
3. Find order and click it
4. Update status: Pending → Confirmed
5. Message: "Order confirmed, preparing shipment"
6. Update: Confirmed → Shipped (add tracking)
7. Customer gets notification
```

### Scenario 2: Product Running Low
```
1. Dashboard shows: "⚠️ Low Stock: 8 products"
2. Click alert or go to "📚 Inventory & Stock"
3. Find product and edit stock
4. Add quantity from recent restock
5. Save changes
6. Stock resets to normal
```

```
5. Discount: 50%
6. Min Spend: ₹1000
7. Valid: Today only
8. Create coupon
9. Share code with customers
```

```
3. Find the review
4. Read customer concern
5. Click "Reply"
```
